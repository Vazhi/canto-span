## Absorbed lexical slice

The runtime audit covers **35 source-listed forms**:

- 25 hobbies and free-time expressions;
- 10 large-number expressions from 一百萬 through 一千萬.

The data is integrated into existing project-native structures rather than preserving the lesson layout:

- transparent activity expressions use existing `ProductiveVO` structure where appropriate;
- conventional or non-compositional activity expressions use bounded `TOKEN_LEXICON` entries;
- 去沙灘 remains motion plus an independently visible destination;
- million expressions are registered lexical data but remain compositionally tokenized;
- learner-facing hover glosses are added for all 25 activity expressions.

## Deduplication and corrections

Existing entries were retained where adequate, including 行山, 聽歌, 睇書, 畫畫, 運動, 公園, and 一千萬. Missing component and phrase coverage was added only where it improved runtime recognition, role assignment, or pronunciation display.

Three source/runtime discrepancies received explicit treatment:

1. Glossika lists 釣魚 as `diu3 jyu2`. Canto Span retains the reviewed lexical reading 魚 `jyu4`; the source tone is not imported.
2. The existing runtime had the noun reading 畫 `waa2` on the drawing verb. The verb is corrected to `waak6`, and 畫畫 is represented as `waak6 waa2`.
3. 公園 defaults to the common changed-tone reading `gung1 jyun2`; `gung1 jyun4` remains an accepted review variant.

The global tokenization of 嘢食 is deliberately unchanged. 煮嘢食 uses a phrase-local food-object token so existing 有冇嘢食 availability-question behavior remains stable.
