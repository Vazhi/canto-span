## Source-supported distinctions

### Cantonese object omission is real but not uniform

Lee (2018) distinguishes specific anaphoric object drop from three non-specific subtypes: existential, generic, and attributive. The paper argues for an NP-ellipsis analysis with an antecedent and reports that its Cantonese examples were accepted by twenty Hong Kong-born speakers. Matthews and Yip's official grammar materials independently illustrate topicalization, topic chains, and omitted pronouns.

These sources establish that an unpronounced object can be licensed and interpreted in several ways. They do not show that every objectless verb has a syntactically present hidden object, nor that all verbs permit the same omission profile.

### `咗` and `喇` must remain separate

The AB30 source ledger and the official aspect chapter classify postverbal `咗` as perfective and keep completion, result, temporal location, and current relevance from being treated as invariant consequences of the marker alone. Fan and Chan (2022) explicitly distinguish `V + 啦` from `V + 咗 + 啦`.

Sybesma and Li (2007) describe `laa3` as marking a realized or newly relevant state in their particle analysis. The official Cantonese grammar also treats sentence-final particles as an independent layer and shows `喇` combining with predicates and with other particles.

Therefore, an objectless `V咗喇` string potentially combines at least three independent questions:

1. what argument structure or lexical sense the verb has in context;
2. what perfective `咗` contributes;
3. what sentence-final `喇` contributes to the discourse update.

## Competing analyses

| Analysis | Description | Current evidence state |
| --- | --- | --- |
| Specific anaphoric null object | A unique previously mentioned object is recovered. | Directly compatible with Cantonese object-drop literature. |
| Non-specific anaphoric null object | The omitted object receives existential, generic, or attributive interpretation from an antecedent. | Directly supported as a Cantonese possibility by Lee (2018), but not yet tested for the pilot verbs. |
| Conventional activity | The verb denotes a familiar activity without requiring identification of a particular object, such as eating or writing in an appropriate context. | Plausible lexical/usage analysis; requires verb-specific evidence. |
| Lexical intransitive or ambitransitive sense | The relevant lexical entry does not project an object in that use. | Must be decided verb by verb; cannot be inferred from surface omission alone. |
| Answer or discourse fragment | A fuller proposition is recoverable from a question or previous turn. | General discourse mechanism; context must be preserved. |
| Event-only perfective assertion | The clause asserts occurrence/completion of an event while no object is semantically selected. | Possible for some predicates or senses; not established as a uniform `V咗喇` construction. |
| Particle-driven current update | `喇` presents the proposition as newly realized or currently relevant. | Supported as an independent particle contribution; does not identify the missing argument. |

## Initial decision map

### Source-supported

- Cantonese permits discourse-recoverable object omission.
- Omitted objects can have specific and several non-specific interpretations.
- Topicalization and topic chains can maintain an antecedent across clauses.
- Perfective `咗` and sentence-final `喇` are separate grammatical layers.
- AB30 is explicitly limited to an overt independently licensed object and must not absorb objectless cases.

### Not yet supported

- a universal hidden-object representation for all objectless `V咗喇` clauses;
- a universal event-only analysis;
- unrestricted omission across transitive predicates;
- equivalence among `V咗`, `V咗喇`, `V完咗`, and `V完咗喇`;
- parser reconstruction of a specific object without overt discourse evidence;
- treating high naturalness as proof of one syntactic analysis.

### Required later evidence

- final frozen pilot audit with item versions and adjudicated interpretations;
- matched contexts with a unique object, a non-unique antecedent, no antecedent, and an explicit conventional activity;
- a verb-class matrix covering consumption, creation, reading/viewing, transfer, handling, motion, and genuinely intransitive predicates;
- separate contrasts for `咗`, `喇`, `咗喇`, `完咗`, and overt objects;
- context-bearing corpus examples that preserve the antecedent and conversational function.

## Working conclusion

The interim result should not be summarized as either “Cantonese freely drops objects” or “the object is optional.” Current sources require a multi-analysis model. Object omission can be anaphoric and can support more than one referential type; some verb uses may instead be lexical or activity readings; and `喇` adds a separate discourse-update layer. The later survey and corpus review must identify which analysis is active for each verb and context.
